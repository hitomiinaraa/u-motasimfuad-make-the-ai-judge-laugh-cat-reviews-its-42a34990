## The entry

A deadpan one-star review written by a house cat about its human, 119 characters:

> One star. He waved the red dot for ten minutes, then put it in a drawer. I have filed a formal complaint with the void.

It keeps the flat shape of a real review while the grievance goes somewhere only a cat would go: the red dot was never caught, the drawer ate it, and the complaint has been filed with the void.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` and prints it to stdout. No dependencies, Node 22+.
